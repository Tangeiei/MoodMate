MoodMate

Student Mood Tracking Web Application

เว็บแอปพลิเคชันบันทึกและวิเคราะห์สุขภาพอารมณ์สำหรับนักศึกษา
ดูแลสภาวะจิตใจผ่านการติดตามความรู้สึก พร้อมกิจกรรมผ่อนคลายและสถิติอัจฉริยะ

Frontend: Angular 22 & Chart.js Backend: Node-RED REST API Database: MySQL 8.0 DevOps: Docker Compose
GitHub: github.com/Tangeiei/MoodMate • GitHub Pages • Cloudflare Live Tunnel
01 / Background & Problem

ที่มาและความสำคัญของปัญหา (Problem Statement)

⚠️ ปัญหาความเครียดของนักศึกษา

นักศึกษาในปัจจุบันเผชิญแรงกดดันจากการเรียน สอบแข่งขัน โปรเจกต์ และปัญหาส่วนตัว ส่งผลให้เกิดความเครียดสะสม อาการหมดไฟ (Burnout) และภาวะซึมเศร้าโดยไม่รู้ตัว

📝 การขาดเครื่องมือติดตามที่เข้าถึงง่าย

คนส่วนใหญ่ไม่มีการจดบันทึกสภาวะอารมณ์อย่างเป็นระบบ ทำให้ไม่เห็นแนวโน้มความเปลี่ยนแปลง และขาดคำแนะนำกิจกรรมดูแลสุขภาพใจที่เหมาะสมในแต่ละวัน

🎯 วัตถุประสงค์ของ MoodMate: สร้างแพลตฟอร์มที่ใช้งานง่าย ปลอดภัย ให้ความเป็นส่วนตัวสูง ช่วยให้นักศึกษาเข้าใจตนเอง รู้เท่าทันอารมณ์ และได้รับคำแนะนำกิจกรรมฟื้นฟูจิตใจอย่างถูกต้อง
02 / Technical Architecture

สถาปัตยกรรมระบบและเครื่องมือที่ใช้ (System Architecture)

🅰️ Frontend Tier
  • Angular 22: SPA Component Architecture
  • SCSS: Pastel Warm & Responsive Design
  • Chart.js: Interactive Visualizations
  • Nginx: Production Web Server Container
🔴 Backend API Tier
  • Node-RED: Flow-based Low-code Engine
  • REST API: /api/auth, /api/moods, /api/analytics
  • Security: bcryptjs (Salt 10) & JWT Token
  • mysql2 Pool: Optimized DB queries
🐬 Database & DevOps
  • MySQL 8.0: Relational Database Engine
  • Data Isolation: Foreign Key Constraints
  • Docker Compose: Multi-container Stack
  • GitHub Pages & Cloudflare: Testing & Tunnel
💡 ระบบถูกออกแบบให้ทำงานร่วมกันเป็นเอกเทศผ่าน Container Network ปลอดภัย ขยายระบบได้ง่าย และสามารถ Deploy ขึ้น Server ใดก็ได้ด้วยคำสั่งเดียว docker compose up -d
03 / Core Features

ฟังก์ชันหลักของระบบ (Core Features)

🔐 ยืนยันตัวตน

ลงทะเบียน & เข้าสู่ระบบด้วย Email + Password เข้ารหัส bcrypt ปลอดภัย แยกข้อมูลส่วนตัวรายบุคคล 100%

😊 เช็คอินอารมณ์

บันทึกอารมณ์ 5 ระดับ (มีความสุข สงบ ปกติ เศร้า กังวล) พร้อมเลือกกิจกรรม แท็ก และบันทึกข้อความรายวัน

📊 สรุปแดชบอร์ด

แสดงการวิเคราะห์รายสัปดาห์ Streak วันที่บันทึกต่อเนื่อง และข้อความสถิติเพื่อให้กำลังใจตนเอง

📜 ประวัติย้อนหลัง

ดูรายการบันทึกย้อนหลัง กรองตามระดับอารมณ์ และช่วงวันที่ พร้อมฟังก์ชันแก้ไขหรือลบรายการได้อย่างอิสระ

ระบบวิเคราะห์ข้อมูลสถิติอารมณ์ (Analytics Engine)

Chart.js Responsive Rendering

05 / Wellness Recommendation

ระบบกิจกรรมดูแลสุขภาพใจ (Self-Care & Wellness)

🧘 กิจกรรมฝึกสติ

เทคนิคการหายใจ 4-7-8, Body Scan ผ่อนคลายกล้ามเนื้อ, และการทำสมาธิสั้น 5 นาทีก่อนเริ่มอ่านหนังสือสอบ

🚶 กิจกรรมผ่อนคลาย

การเดินรับแสงแดด, ยืดเส้นแก้ Office Syndrome, และการฟังเสียงธรรมชาติ (Sound Therapy)

📖 การจัดระเบียบความคิด

บันทึกความรู้สึกขอบคุณ (Gratitude Journal), การเขียนระบายความกังวล (Brain Dump)

💡 Personalized Recommendation: ระบบสามารถแนะนำกิจกรรมที่สอดคล้องกับคะแนนอารมณ์ที่บันทึก เช่น หากบันทึกว่า "กังวล / เศร้า" ระบบจะแนะนำแบบฝึกหายใจและพักสายตาทันที
06 / Security & Architecture

ความปลอดภัยและการปกป้องข้อมูลส่วนบุคคล (Security & Privacy)

🔒 Password Hashing

รหัสผ่านถูกเข้ารหัสด้วยอัลกอริทึม bcrypt (Salt rounds 10) ก่อนจัดเก็บลงฐานข้อมูล ป้องกันการรั่วไหล 100%

🎟️ JWT Token Auth

การยืนยันสิทธิ์ผ่าน JSON Web Token กำหนดอายุ Token ชัดเจน ส่งผ่าน HTTP Authorization Header อย่างรัดกุม

🛡️ Strict Data Isolation

ทุก Query ใน Node-RED ตรวจสอบ user_id เสมอ ผู้ใช้แต่ละคนจะไม่สามารถเข้าถึงหรือเห็นข้อมูลอารมณ์ของผู้อื่นได้

⚡ Database Integrity & Volume Persistence

ใช้ Foreign Key Constraints พร้อม ON DELETE CASCADE เมื่อลบบัญชี ข้อมูลอารมณ์จะถูกลบอย่างสะอาดหมดจด และข้อมูลถูกจัดเก็บใน Docker Persistent Volume ไม่สูญหายแม้ Restart เครื่อง

08 / Deployment & Access

การติดตั้งและการเข้าใช้งานผ่านมือถือ (Deployment & Mobile)

📦 Docker Compose

รันทั้งระบบด้วยคำสั่งเดียว มี 3 คอนเทนเนอร์ (Frontend, Backend, Database) มี Healthcheck และ Auto-restart

🌐 GitHub Pages

โฮสต์หน้าเว็บเวอร์ชันพรีวิวบน GitHub Pages ให้ทุกคนสามารถเข้าชมการจัดวางและดีไซน์ UI ได้ทันที

📲 Mobile Live Tunnel

มี Script รัน Cloudflare Tunnel เชื่อมต่อมือถือเข้ากับเครื่องเดโมผ่าน HTTPS ได้อย่างปลอดภัยโดยไม่ต้องเปิดพอร์ตเราเตอร์

🚀 สคริปต์อำนวยความสะดวกสำหรับผู้นำเสนอ

สร้างไฟล์ start-mobile.bat ดับเบิลคลิกเปิดระบบ Tunnel ให้มือถือสแกนเข้าใช้งานได้ในคลิกเดียว พร้อมคัดลอกลิงก์ให้อัตโนมัติ
