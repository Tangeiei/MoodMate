MoodMate

Student Mood Tracking Web Application
เว็บแอปพลิเคชันบันทึกและวิเคราะห์สุขภาพอารมณ์สำหรับนักศึกษา

01 / Background & Motivation

ที่มาและความสำคัญของปัญหา (Problem Statement)

⚠️ ปัญหาด้านสุขภาพใจในชีวิตมหาวิทยาลัย
  • ภาวะความเครียดสะสม: นักศึกษาเผชิญแรงกดดันจากการเรียน สอบ งานกลุ่ม และการปรับตัว
  • ขาดการรู้เท่าทันอารมณ์ตนเอง: ไม่ทราบว่าช่วงเวลาใดที่ความเครียดสูง จนนำไปสู่อาการ Burnout หรือภาวะซึมเศร้า
  • ขาดเครื่องมือติดตามที่เข้าถึงง่าย: แอปพลิเคชันทั่วไปซับซ้อน หรือมีค่าใช้จ่าย และไม่ตอบโจทย์นักศึกษา
🌱 โซลูชัน: MoodMate Web Application
  • บันทึกอารมณ์ประจำวันง่ายใน 1 นาที: เลือกคะแนนอารมณ์ 5 ระดับ ระบุปัจจัยต้นเหตุ และชั่วโมงการนอน
  • สถิติและการวิเคราะห์เชิงลึก: เห็นความสัมพันธ์ระหว่างการนอน พลังงาน และอารมณ์ผ่านกราฟทันที
  • แนะนำกิจกรรมดูแลใจ (Self-Care): ระบบแนะนำแบบฝึกหายใจและกิจกรรมผ่อนคลายที่เหมาะกับสภาพจิตใจ
🎯 วัตถุประสงค์สูงสุด: ส่งเสริมสุขภาวะทางอารมณ์ที่ดี (Emotional Well-being) ให้นักศึกษาสามารถเข้าถึงเครื่องมือดูแลตนเองได้ทุกที่ ทุกเวลา อย่างเป็นส่วนตัว ปลอดภัย และไร้ค่าใช้จ่าย
02 / Technical Architecture

สถาปัตยกรรมระบบและเครื่องมือที่ใช้ (System Architecture)

🅰️ Frontend Tier
  • Angular 22: Standalone Component & Signals
  • SCSS: Modern Warm Pastel Responsive Theme
  • Chart.js: Interactive Visualizations
  • Nginx: Production Containerized Web Server
🔴 Backend API Tier
  • Node-RED: Flow-based Visual REST API
  • Security: bcryptjs (Salt 10) & JWT Token
  • Endpoints: /api/auth, /api/moods, /api/analytics
  • mysql2 Pool: รองรับการเข้าถึงข้อมูลพร้อมกัน
🐬 Database & DevOps
  • MySQL 8.0: Relational Database Engine
  • Data Isolation: Foreign Key Constraints
  • Docker Compose: สั่งรันทุกระบบในคำสั่งเดียว
  • Cloudflare Tunnel: เชื่อมต่อมือถือเข้าทดสอบจริง
Client Browser / Mobile ⇆ Nginx Proxy (:8080) ⇆ Node-RED Engine (:1880) ⇆ MySQL Database (:3306)
03 / Screen Walkthrough

ระบบสมัครสมาชิกและยืนยันตัวตน (Authentication)

🔐 การรักษาความปลอดภัยบัญชีผู้ใช้
  • แยกข้อมูลรายบุคคล 100% (User Isolation): ผู้ใช้แต่ละคนมองเห็นเฉพาะบันทึกของตนเอง
  • การเข้ารหัสผ่าน (Password Hashing): ใช้ bcryptjs (Salt 10) ก่อนบันทึกลงฐานข้อมูล
  • JSON Web Token (JWT): ออก Token ตรวจสอบสิทธิ์ทุก Request ผ่าน Authorization Header
  • การป้องกันอีเมลซ้ำ: ตรวจสอบ Unique Email ในฐานข้อมูลและส่ง Error แจ้งเตือนชัดเจน
04 / Screen Walkthrough

แดชบอร์ดสรุปผลสุขภาพใจประจำวัน (Student Dashboard)

📊 ฟังก์ชันเด่นบนหน้าแดชบอร์ด
  • Personalized Greeting: แสดงชื่อนักศึกษา คำแนะนำประจำวัน และสถิติ Streak วันที่บันทึกต่อเนื่อง
  • Today Status: แสดงสถานะการเช็คอินของวันนี้ทันที หากยังไม่ได้บันทึกจะมีปุ่มกดเช็คอิน
  • Weekly Summary: การ์ดสรุปคะแนนอารมณ์เฉลี่ย, สถิติการนอนหลับ และระดับพลังงาน
  • Data Synchronization: โหลดข้อมูลแบบ Reactive ด้วย RxJS ปราศจากปัญหาค้างหรือ Loading ไม่รู้จบ
05 / Screen Walkthrough

ระบบเช็คอินและบันทึกอารมณ์ (Daily Mood Check-in)

📝 ขั้นตอนการบันทึกอารมณ์
  • 1. เลือกระดับอารมณ์ 5 ระดับ: มีความสุขมาก (5), สงบ/ดี (4), ปกติ (3), เศร้า/เหนื่อย (2), กังวล (1)
  • 2. ปัจจัยต้นเหตุ (Factors): เช่น การเรียน, การสอบ, เพื่อน, คนรัก, ครอบครัว, สุขภาพ
  • 3. พลังงานและการนอนหลับ: ระบุชั่วโมงการนอนและระดับพลังงาน (1-5)
  • 4. ไดอารี่ระบายความรู้สึก: บันทึกข้อความสั้น ๆ เพื่อสะท้อนความคิดในแต่ละวัน
06 / Screen Walkthrough

การวิเคราะห์และแสดงผลสถิติแนวโน้ม (Analytics Engine)

📈 การประมวลผลข้อมูลสถิติสุขภาพใจ
  • Mood Trend Line Chart: กราฟเส้นแสดงทิศทางอารมณ์ย้อนหลัง 7 วัน และ 30 วัน สังเกตการเปลี่ยนแปลงได้ทันที
  • Mood Distribution Doughnut: แผนภูมิโดนัทแสดงสัดส่วนเปอร์เซ็นต์ของอารมณ์ในภาพรวม
  • Correlation Analysis: วิเคราะห์ความสัมพันธ์ระหว่างชั่วโมงการนอนและอารมณ์
  • Interactive Chart.js: เลื่อนเมาส์ดู Tooltip ข้อมูลวันที่และคะแนนอย่างละเอียด
07 / Screen Walkthrough

ประวัติอารมณ์ย้อนหลังและกิจกรรมดูแลใจ (History & Self-Care)

📜 ประวัติอารมณ์ย้อนหลัง (กรองตามวันที่และอารมณ์ / แก้ไข / ลบ)
🧘 คลังกิจกรรมดูแลใจ (ฝึกหายใจ 4-7-8, พักสายตา 20-20-20, ฟังเสียงธรรมชาติ)
08 / Verification & Access

การทดสอบระบบและการใช้งานบนมือถือ (Mobile View & QA)

📱 การเข้าถึงผ่านสมาร์ตโฟน & ความพร้อมใช้งาน
  • Mobile-First Responsive: ปรับ Layout ให้พอดีกับหน้าจอมือถือ ปุ่มกดถนัดมือ อ่านง่าย
  • Cloudflare Live Tunnel (HTTPS): เข้าใช้งานผ่านสมาร์ตโฟนได้จริงโดยไม่ต้องอยู่ในวง LAN เดียวกัน
  • Automated Test Suite (21/21 Pass 100%):
    • ผ่านการทดสอบ Register, Duplicate Check, Login/Logout
    • ผ่านการทดสอบ CRUD Mood Entries & Date Constraint
    • ผ่านการทดสอบ Data Isolation ป้องกันผู้ใช้ข้ามสิทธิ์กัน
    • ผ่านการทดสอบ Database Persistence ข้อมูลไม่สูญหายหลัง Restart
